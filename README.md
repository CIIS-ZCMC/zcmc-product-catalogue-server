## Overview

The **ZCMC Product Catalogue Server** is a robust RESTful API built on **Laravel 12** designed to enforce uniform item naming, multi-level category classification, and structured tracking for hospital procurement.

It integrates both international classification (**UNSPSC** — United Nations Standard Products and Services Code) and ZCMC's institutional category standards, automatically generating unique ERP Item Codes and facilitating seamless synchronization across hospital inventory and government procurement portals.

---

## Key Features

- **UNSPSC 4-Level Category Hierarchy:** High-performance materialized path tree supporting Segments, Families, Classes, and Commodities (over 150,000+ classification nodes).
- **Institutional Internal Categories:** 32 specialized ZCMC hospital procurement categories (e.g. `ME-SUP`, `OF-SUP`, `DR-MED`, `IT-EQP`).
- **Autogenerated ERP Item Codes:** Enforces rule `[category->code]-[internal category code]-[seq starting at 01]` (e.g., `44121704-OF-SUP-01`) with automatic sequence calculation and database uniqueness guarantees.
- **Hospital Uniform Naming Assistant:** Live syntax analysis and duplicate similarity detection for standardized item descriptions.
- **System Integration Codes:** Strict tracking for hospital ERP, BizBox system codes, and PS-PhilGEPS portal codes.
- **High-Performance CSV Export & Import:** Streamed CSV processing for massive catalogue data matching procurement templates.
- **LAN & Network Ready:** Preconfigured for local area network access across hospital intranet workstations.

---

## Tech Stack & Architecture

- **Framework:** Laravel 12 (PHP 8.2+)
- **Database:** MySQL / MariaDB
- **Design Principles:** SOLID Architecture, Single Responsibility Services (`ProductService`, `UniformNamingService`, `ProductExportImportService`), FormRequest validation.
- **Authentication / API:** Laravel Sanctum / Token-based API

## Installation & Setup

### Prerequisites
- PHP >= 8.2 with PDO, OpenSSL, Mbstring, and Tokenizer extensions
- Composer >= 2.0
- MySQL >= 8.0 or MariaDB >= 10.4

### Quick Start

1. **Clone the repository:**
   ```bash
   git clone https://github.com/<your-organization>/zcmc_product_catalogue_server.git
   cd zcmc_product_catalogue_server
   ```

2. **Install PHP dependencies:**
   ```bash
   composer install
   ```

3. **Configure environment:**
   ```bash
   cp .env.example .env
   php artisan key:generate
   ```

4. **Update database configuration in `.env`:**
   ```ini
   DB_CONNECTION=mysql
   DB_HOST=127.0.0.1
   DB_PORT=3306
   DB_DATABASE=zcmc_product_catalogue
   DB_USERNAME=root
   DB_PASSWORD=your_password
   ```

5. **Run migrations and seeders:**
   ```bash
   php artisan migrate --seed
   ```
   *Note: This automatically seeds UNSPSC categories, ZCMC internal categories (32 items), and initial product catalogue items.*

6. **Start development server:**
   - For local access only:
     ```bash
     php artisan serve
     ```
   - For hospital Local Area Network (LAN) access across other PCs:
     ```bash
     php artisan serve --host=0.0.0.0 --port=8000
     ```

## API Reference Summary

| Method | Endpoint | Description |
| :--- | :--- | :--- |
| `GET` | `/api/dashboard/stats` | Summary counts, compliance rates, and recent catalogue items |
| `GET` | `/api/internal-categories` | List all 32 ZCMC institutional categories |
| `GET` | `/api/categories/commodities?q=` | Fast searchable autocomplete for UNSPSC Commodities |
| `GET` | `/api/categories/roots` | List root UNSPSC Segments (Level 0) |
| `GET` | `/api/categories/{key}/children` | Fetch immediate subcategories for a category key |
| `GET` | `/api/products` | Paginated product list with search and filters |
| `GET` | `/api/products/next-erp-code` | Calculate next sequential ERP code (`?category_code=&internal_category_code=`) |
| `GET` | `/api/products/{id}` | Single product details with full hierarchy breadcrumb trail |
| `POST` | `/api/products` | Create new product catalogue item |
| `PUT` | `/api/products/{id}` | Update existing product |
| `DELETE` | `/api/products/{id}` | Remove product from catalogue |
| `POST` | `/api/products/validate-naming` | AI/Rule-based uniform naming analysis |
| `GET` | `/api/products/export` | Streamed CSV download matching procurement template |
| `POST` | `/api/products/import` | Upload and ingest catalogue CSV |
